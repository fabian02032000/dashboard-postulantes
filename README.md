# Dashboard de postulantes (Netcall)

Página con gráficos de los postulantes que llegan al sheet "RECLUTAMIENTO MULTICAMPAÑA".

- `index.html`: la página (se publica con GitHub Pages).
- `data.json`: los datos. Los sube solo el script de Google Sheets, cada vez que algo cambia.

Solo hay números: no hay nombres, teléfonos, correos, DNI ni enlaces de CV.
